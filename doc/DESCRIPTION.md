OpenCode is an open-source AI coding agent with a terminal interface and a
web UI. This package installs the latest V2 release on YunoHost and lets you
choose between access through the YunoHost web proxy, an encrypted OpenTunnel
proxy, or a VPN-only/private address.

It can use local Ollama models and, optionally, one external provider (OpenAI,
Anthropic or Mistral) configured with an API key from the YunoHost config panel.

The agent runs as a dedicated system user. It can execute shell commands and
edit files, so only grant access to people you trust.
